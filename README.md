# redpepper — 홍고추 도매가격 예측

AgriForecast(건국대 팀프로젝트)에 붙일 **홍고추 순별 도매가격 예측 모델**의 데이터·실험 저장소.
서비스 파이프라인은 [aws-agriforecast](https://github.com/KCSP-konkuk/aws-agriforecast) 에 있고,
여기에는 품목 선정부터 피쳐 탐색·성능 검증까지의 근거가 들어 있다.

## 성능 (1순 앞, 연도별 홀드아웃 2021~2025)

나이브 = 직전 순 가격. 배추는 같은 틀에서 각자 최적 구성으로 튜닝해 비교했다.

| | R² | MAE | RMSE | MAPE | MdAPE | MASE | RMSSE | 방향정확도 |
|---|---|---|---|---|---|---|---|---|
| **홍고추 모델** | 0.779 | 16,133 | 21,714 | 18.7% | 15.5% | **0.759** | 0.773 | 72.2% |
| 홍고추 나이브 | 0.629 | 21,268 | 28,089 | 24.7% | 20.2% | 1.000 | 1.000 | — |
| 배추 모델 | 0.823 | 1,371 | 1,885 | 14.0% | 10.8% | 0.870 | 0.831 | 61.7% |
| 배추 나이브 | 0.744 | 1,576 | 2,269 | 15.5% | 12.0% | 1.000 | 1.000 | — |

- Diebold-Mariano(HLN 보정): 홍고추 절대손실 t=-5.14 (p<0.0001), 제곱손실 t=-4.34 (p<0.0001) — 나이브 대비 개선이 유의하다. 배추는 t=-2.78 (p=0.006).
- 연도별 MASE: 홍고추 0.80·0.74·0.72·0.76·0.78 로 **전 연도 1 미만**. 배추는 2021~2025 중 2년이 1 이상.
- MAPE 를 품목끼리 직접 비교하면 안 된다. 나이브 MAPE 자체가 홍고추 24.7%, 배추 15.5% 로 출발선이 다르다. 공정한 비교는 MASE·RMSSE.

## 모델 구성

- 타깃: 다음 1순 가격 ÷ 직전 순 가격(비율). 수준을 직접 맞히면 학습 범위 밖 가격대에서 무너진다.
- 피쳐: 가격 자기이력 + **교차 품목가(풋고추·청피망)** + **검색량(고춧가루)** + 명절·수확기 더미
- 중요도 상위 80개 선택 후 XGBoost, 시드 12개 평균. 설정은 `experiments/best_soon.json`.
- 효과 없던 것: 기상(ASOS 6지점), 반입량, 출하지역, 물가지수(PPI 건고추 등), 재배면적·생산량, LightGBM·RF·Ridge·Huber, 앙상블, 상·중·하순 분리 모델.

## 재현

```bash
pip install -r requirements.txt
cd experiments
python report2.py        # 홍고추 vs 배추 최종 비교표 + DM 검정
python tune_redpepper.py # 피쳐 개수·하이퍼파라미터 재탐색
```

`collect/` 의 수집 스크립트 중 기상청·KOSIS·데이터랩은 API 키를 서버 설정 파일에서 읽는다(키는 이 저장소에 없다). 농넷은 인증이 없어 그대로 돌아간다.
